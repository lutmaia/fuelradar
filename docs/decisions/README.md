# Decisões de arquitetura

Registros curtos de uma decisão, seu contexto e consequências (ADRs), numerados a partir de 0001. As decisões tomadas antes desta pasta existir, chamadas ADR-001 a ADR-007, ficam na seção 26 de [architecture.md](../architecture.md) e são outra numeração: não confundir com os arquivos 0001 a 0007 daqui.

Um registro novo indica status, contexto, decisão, alternativas e consequências; não duplique nem reescreva os existentes, acrescente um adendo datado.
